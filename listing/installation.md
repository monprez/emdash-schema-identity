1. Install the plugin and approve its one permission, reading bylines. It makes no network requests and never changes your content.
2. **Identity**: choose a person, an organisation or both, fill in what is true, and link your own byline if you write on the site. Set the time zone that decides when a credential expires.
3. **Credentials**: add the site person's credentials and the organisation's certifications.
4. **People**: add job titles, expertise and credentials for each byline. Name, bio and website stay on the byline itself.
5. **Byline roles**: map any role labels your bylines use, such as "Reviewed by".

Then paste a published article into Google's Rich Results Test; the Identity page links to it.

Structured data should match what readers see. To show credentials on the page too, see [Show what you publish](https://github.com/monprez/emdash-schema-identity#show-what-you-publish) for the public route and a copyable author box.

Use one schema plugin at a time: only one can own the page's JSON-LD. Needs EmDash 1.2.0 or later. English-only for now, built for single-language sites.
